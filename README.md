# FlameDrop
FlameDrop is a lightweight, self-hosted file-sharing service built with Python. It provides a web-based interface for transferring files between devices, with a simple setup and convenient access through a browser. Designed for easy deployment, FlameDrop offers a practical way to share files over your network without relying on third-party file-sharing platforms.
